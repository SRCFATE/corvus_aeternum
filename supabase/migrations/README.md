# Migraciones

Estas son las migraciones versionadas de Corvus. El nombre de cada archivo
coincide con la versión registrada en el proyecto de Supabase, así que
`supabase migration list` las reconoce como aplicadas.

Las migraciones anteriores a septiembre de 2026 se aplicaron directamente sobre
el proyecto remoto y **solo existen allí**; los esquemas de referencia de
aquella etapa están en `docs/*.sql`. A partir de aquí, toda migración se
versiona aquí junto al commit que la motiva.
